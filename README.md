# Rabia Tabbassam — Personal Portfolio

A responsive, dark-themed personal portfolio introducing Rabia Tabbassam, a BS Mathematics student exploring Python development, data analytics and AI automation.

## Preview locally

No build tools or package installation are required.

1. Download or clone this repository.
2. Open the repository folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Project files

- `index.html` — portfolio content and page structure
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation and rotating role text
- `404.html` — custom not-found page
- `assets/favicon.svg` — RT monogram favicon
- `rabia` — original portfolio brief, preserved

## Deploy with GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `rabia-premium-portfolio` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

For Vercel, import this repository, select the `rabia-premium-portfolio` branch, choose the root directory, and deploy as a static site with no build command.

## Accessibility and responsiveness

The site includes semantic sections, keyboard focus styling, a mobile navigation menu, responsive layouts and reduced-motion support.
